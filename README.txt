Production
Simply push code to master branch of https://github.com/thomasmatt88/thomasmatt88.github.io 
- pages-build-deployment workflow runs automatically upon push to 'master' branch
- pages-build-deployment yaml is not modifiable but can be configured via Settings -> Pages
- can opt to publish via your own custom workflow via Settings -> Pages -> Source -> GitHub Actions
- documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
